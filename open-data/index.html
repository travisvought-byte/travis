Open data

The directories on these sites are open data. Anyone may copy and reuse them with credit, so no one has to collect the same listings twice, and people get to the help they need faster.

Projects that keep similar data are welcome to link with us. Data is shared under Creative Commons Attribution 4.0 (CC BY 4.0); the code that builds each site is under the MIT License.

Data you can reuse

Each dataset below is free to copy, change and share, including for commercial use, as long as you give the credit line shown.

  • Mobility Talk

    mobilitytalk.org

    What it covers
    Disability and mobility programs for all 50 states, D.C. and the U.S. territories: equipment repair, coverage, home access, benefits, housing, rides, rights and more.
    License
    Data under CC BY 4.0, code under MIT. Read the Mobility Talk license.
    Credit line
    "Mobility Talk, created by Travis Vought."
    Where to get it
    Mobility Talk data folder on GitHub

  • Veteran Resident Resource Guide and Find Bingo

    guide.vethomeguard.org and findbingo.org

    What it covers
    Benefits, care, housing and local offices for veterans, surviving spouses, seniors and people with disabilities in all 50 states and D.C., plus the bingo games, halls and senior centers listed on Find Bingo.
    License
    Data under CC BY 4.0, code under MIT. Read the guide's license.
    Credit line
    "Veteran Resident Resource Guide, created by Travis Vought and shared by Veteran Home Guardians."
    Where to get it
    Veteran guide and Find Bingo data folder on GitHub

  • Ohio Cannabis Ecosystem Directory

    OhioWeed.org and the-reefer.com

    What it covers
    Ohio cannabis operators, service providers, nonprofits and related organizations, each traced to a named source, with documented business-to-business relationships and dispensary locations.
    License
    Data under CC BY 4.0, code under MIT. Read the directory's license.
    Credit line
    "Ohio Cannabis Ecosystem Directory, compiled by Travis Vought."
    Where to get it
    Ohio cannabis directory data folder on GitHub. The CSV downloads sit at the top of the same repository.

Open projects we draw on or point to

Other people keep good data too. These are the open sources and projects the guides use or send people to.

Veterans

  • Warriors Fund veteran resource database: open data under CC BY 4.0, also published in the Open Referral format.
  • VA Facilities API: the guide's VA locations come from it.
  • NASVH directory of State Veterans Homes: where to find each state's veterans homes.

Mobility

  • Project Sidewalk, Columbus: volunteers map missing curb ramps and sidewalk barriers, and the results are open data.
  • Wheelmap: wheelchair accessibility of places, recorded on OpenStreetMap.
  • AT3 Center state assistive technology programs: contacts for each state's assistive technology program.

Bingo

  • Ohio Attorney General charitable bingo: the state office that licenses charitable bingo in Ohio.
  • Texas bingo conductor locations: an open government list of licensed bingo conductors in Texas.

Cannabis

  • Cannlytics cannabis license data: open data on licensed cannabis businesses.
  • PDAPS Retail Marijuana Laws: a legal dataset on state retail marijuana laws.

Shared format

  • Open Referral Human Services Data Specification: the common format 211s and referral directories use for service listings.

Link with us

If you keep a similar dataset, reach Travis through the Veteran Home Guardians contact page so we can point to each other, share corrections and keep from duplicating the work.
